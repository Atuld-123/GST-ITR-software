# Commercial MVP Roadmap

## Delivered foundation

- Secure organization-scoped identity, membership and role foundation
- CA multi-client management with PAN uniqueness per organization
- Double-entry journal validation and chart-of-accounts API foundation
- GST registration, validated sales invoices, tax split, and prepared GSTR-1 summary
- Local PostgreSQL/Redis environment, migrations, health endpoint and API documentation
- Encrypted document API, audit trail, organization permission checks, internal GSTR-1 review/export workflow
- Containerized production stack draft with private data services, separated database runtime/migration accounts and HTTPS edge
- CA-review draft of limited AY 2026-27 salary-only old/new regime tax estimate

## Next delivery order

1. Purchase invoices and GST purchase register
2. GSTR-3B preparation and effective-dated compliance calendar
3. GSTR-2B import and explainable invoice reconciliation
4. Expand the limited AY 2026-27 salary estimate into CA-reviewed rule-versioned ITR-1 and ITR-4 preparation
5. Financial reporting, export workflows, document collection and reminders

Live filing, e-invoice/e-way bill, OCR, messaging, banking and government portal connections remain separate release gates. They require authorized credentials, sandbox validation, rule review, and verified acknowledgement handling.
